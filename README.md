# geoTotal

Globo terrestre interativo com os países, capitais e regiões do mundo (e os estados do Brasil),
com modo de treino, comparação entre países e distância entre capitais. Funciona como app Android,
sem precisar de internet.

**Criado por [alessandrocdrx](https://github.com/alessandrocdrx).**

## Baixar e instalar no Android

Abra este link no celular, **pelo Chrome**:

https://github.com/alessandrocdrx/GeoTotal/releases/latest/download/geototal.apk

Toque em **Baixar mesmo assim** → **Abrir** → **Instalar** (se o Android pedir, ative
"Permitir desta fonte"). Detalhes de como compilar e publicar versões novas em
[`android/README.md`](android/README.md).
